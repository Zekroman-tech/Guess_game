# Игра "Угадай число"

## Описание
Консольная игра на Python, в которой компьютер загадывает 
случайное число, а игрок пытается его угадать.

## Возможности
- Три уровня сложности (лёгкий, средний, сложный)
- Подсчёт попыток
- Обработка ошибок ввода (буквы вместо цифр)
- Проверка диапазона введённых чисел
- Счёт побед за сессию
- Возможность играть несколько раз подряд

## Технологии
- Python 3
- Модуль `random` для генерации случайных чисел

## Как запустить
1. Установи Python 3 с официального сайта
2. Скачай файл `guess_game.py`
3. Запусти командой: `python guess_game.py`
